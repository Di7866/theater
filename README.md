# Театр
Учебное веб-приложение для зрителей, которое объединяет функции интерактивной афиши и системы бронирования. 
# Назначение проекта
Проект представляет собой демонстрационную версию веб-сайта театра, предназначенную для выбора спектаклей и бронирования билетов онлайн. <br> Главная цель сайта — предоставить пользователю простую, понятную и быструю точку для планирования культурного досуга в один клик.
